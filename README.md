# BMI-kalkulator-app

Aplikasi Kalkulator Indeks Massa Tubuh (BMI) sederhana yang dibangun menggunakan **Java**, antarmuka grafis **JavaFX**, dan dikelola dengan **Maven**. Antarmuka (UI) dirancang secara visual menggunakan **Scene Builder**.

Aplikasi ini menerima input berat badan (kg) dan tinggi badan (cm) pengguna, lalu mengkalkulasi skor BMI beserta status kesehatan berdasarkan standar umum.

## ⚙️ Cara Menjalankan Aplikasi
1.  **Buka Proyek:**
    *   Buka Apache NetBeans.
    *   Pilih `File > Open Project...` dan pilih folder proyek `bmicalc` ini.
  
2.  **Clean and Build:**
    *   **Klik kanan** pada nama proyek di panel *Projects* sebelah kiri.
    *   Pilih **Clean and Build**.
  
3.  **Run**
